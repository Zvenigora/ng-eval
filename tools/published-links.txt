# Links into this repository that a published README prints (docs/backlog-retired.md F25 Part 4).
#
# A README in a tarball on npm links this repository at `master`, so each link resolves against
# whatever `master` holds, for as long as that version is installed. A published link therefore
# binds: tools/doc-links.mjs resolves every line below against the tree, and fails when a target
# file or anchor stops existing. A move of a bound file leaves a stub at the old path linking the
# new one. The retirement of a backlog entry whose anchor is bound gives its index row in
# docs/backlog.md that anchor, <a id="…"></a>, in the first cell.
#
# One URL per line, in the form doc-links resolves: https://github.com/zvenigora/ng-eval followed
# by /blob/master/<path> or /tree/master/<path>, or the bare repository root with or without
# #readme. A link of that form in a modules/*/README.md must be listed here before it is published,
# or doc-links fails with "not recorded". A line is never removed while a version that prints it
# stays on npm.
#
